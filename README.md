# Death Messages
Shows a random message of your choosing at random when you die.
Press the cogwheel in the bottom left corner to open the mod settings. From there, press the folder icon to find the phrases.txt file. Edit it to add or remove phrases.

Ayden123kitten has made a long list of horrible messages. If you are too lazy to write your own messages, you can download it here:
https://github.com/Ayden123kitten/custom-geode-deathmessages/blob/main/deathMessages.txt
